# Leaderboard — Discord-бот

Бот показывает таблицу лидеров тремя частями по командам:

| Команда     | Места  |
|-------------|--------|
| `!top-10`   | 1–10   |
| `!top-20`   | 11–20  |
| `!top-30`   | 21–30  |

Каждое место — отдельная карточка жирным заголовком:
```
# {номер}.{Ник Roblox}({пинг Discord})
# {ссылка на профиль Roblox}
```
Карточки внутри одного сообщения разделены настоящей линией-разделителем (Discord Components V2), а не просто пустой строкой.

Если для места не заданы переменные окружения — вместо конкретного отсутствующего поля подставляется `[VACANT]` (например, Roblox-ник может быть заполнен, а ссылка — нет, тогда именно она станет `[VACANT]`).

### Про "пинг" в `RANK_<N>_DISCORD`

Чтобы в карточке был настоящий кликабельный пинг пользователя, в переменную нужно положить **Discord ID** этого человека (число из 15–20 цифр), а не никнейм текстом:

```
RANK_1_DISCORD=123456789012345678
```

ID можно получить, включив в Discord Настройки → Расширенные → Режим разработчика, затем ПКМ по пользователю → «Копировать ID».

Если вместо ID оставить обычный текст (никнейм) — бот покажет его как есть, просто текстом, без функции пинга.

Пинг не шлёт уведомление участнику при каждом вызове команды (настроено через `allowedMentions`), но остаётся кликабельным и подсвеченным.

## 1. Создание бота в Discord

1. Зайдите на https://discord.com/developers/applications → **New Application**.
2. Вкладка **Bot** → **Reset Token** → скопируйте токен (понадобится как `DISCORD_TOKEN`).
3. В том же разделе Bot включите **Message Content Intent** (без него бот не увидит текст команд).
4. Вкладка **OAuth2 → URL Generator**: отметьте scope `bot`, права как минимум `Send Messages`, `Embed Links`, `Read Message History`. Полученной ссылкой пригласите бота на сервер.

## 2. Переменные окружения

Локально скопируйте `.env.example` в `.env` и заполните нужные значения (для локального запуска дополнительно понадобится пакет `dotenv`, если хотите подтягивать `.env` автоматически — сейчас index.js читает `process.env` напрямую, что подходит для Railway).

Обязательная переменная:
- `DISCORD_TOKEN` — токен бота.

Необязательная:
- `PREFIX` — префикс команд, по умолчанию `!`.

Данные лидерборда — по 3 переменные на каждое место с 1 по 30:
```
RANK_<N>_DISCORD
RANK_<N>_ROBLOX
RANK_<N>_LINK
```
где `<N>` от 1 до 30. Незаполненные переменные не нужно удалять — просто оставьте их пустыми или вообще не создавайте, бот сам подставит `[VACANT]`.

## 3. Деплой на Railway

1. Создайте новый проект на Railway → **Deploy from GitHub repo** (или загрузите этот код через Railway CLI).
2. В разделе **Variables** добавьте `DISCORD_TOKEN` и все 90 переменных `RANK_*` (можно добавлять только те места, которые уже заполнены — остальные автоматически станут `[VACANT]`).
3. Railway автоматически определит `npm start` из `package.json`. Убедитесь, что установлен Node.js 18+. Разделители и заголовки требуют `discord.js` версии 14.16.3 или новее — она уже указана в `package.json`, просто убедитесь, что Railway ставит зависимости заново (`npm install`), а не использует старый кэш.
4. После деплоя проверьте логи — должна появиться строка `Бот запущен как <имя_бота>#0000`.

## 4. Локальный запуск (для проверки)

```bash
npm install
DISCORD_TOKEN=ваш_токен node index.js
```
