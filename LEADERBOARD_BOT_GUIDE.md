# 🏆 VORTEX Leaderboard Bot — Полное руководство

## 📋 Описание системы

**Leaderboard Bot** — полностью автоматизированная система лидерборда с боевой системой дуэлей.

### Основные команды:
- `!top-10` → места 1–10
- `!top-20` → места 11–20  
- `!top-30` → места 21–30
- `!leaderboard` → создать основное сообщение с кнопкой для претензий

---

## 🎯 Как работает система

### 1️⃣ Претензия на свободное место
1. Игрок нажимает кнопку **"Атаковать место"** на основном сообщении лидерборда
2. Открывается форма с 4 вопросами:
   - На какое место претендуете? (1-30)
   - Ник Discord
   - Ник Roblox
   - Ссылка на профиль Roblox
3. Если место **свободно** → игрок сразу встаёт туда, лидерборд обновляется
4. Если место **занято** → объявляется **дуэль** в канале дуэлей

### 2️⃣ Дуэльная система (3 дня)
1. В канале дуэлей публикуется сообщение:
   ```
   ⚔️ ДУЭЛЬ ⚔️
   @Attacker атакует место 5!
   @Defender защищается.
   ```
2. Игроки **проводят дуэль за 3 дня**
3. **Если выигрывает атакующий:**
   - Нажимает кнопку "Атакующий выиграл"
   - Атакующий встаёт на место защитника
   - Если атакующий БЫЛ в лидерборде → его старое место переходит защитнику
   - Если атакующий НЕ БЫЛ в лидерборде → защитник удаляется из лидерборда
4. **Если выигрывает защитник:**
   - Никакой действия не требуется
   - По истечению 3 дней кнопка блокируется и лидерборд не изменяется

## ⚙️ Развёртывание на Railway

### Шаг 1: Создание бота в Discord Developer Portal

1. Зайди на [discord.com/developers/applications](https://discord.com/developers/applications)
2. Нажми **New Application** → дай имя "Leaderboard Bot"
3. Вкладка **Bot** → нажми **Add Bot**
4. Включи эти **Privileged Gateway Intents:**
   - ✅ Message Content Intent
5. Скопируй **Token** (будет нужен как `DISCORD_TOKEN`)
6. Вкладка **OAuth2** → **URL Generator**:
   - Scope: `bot`
   - Permissions: `Send Messages`, `Read Message History`, `Manage Messages`, `Embed Links`
7. Скопируй сгенерированную ссылку, открой в браузере и приглаши бота на сервер

### Шаг 2: Загрузка кода на GitHub

1. Создай новый приватный репозиторий `vortex-leaderboard-bot`
2. Загрузи туда два файла:
   - `leaderboard-bot.js` (переименуй из `leaderboard-bot.js`)
   - `package.json` (переименуй из `leaderboard-package.json`)

### Шаг 3: Развёртывание на Railway

1. Зайди на [railway.app](https://railway.app)
2. **New Project** → **Deploy from GitHub repo** → выбери `vortex-leaderboard-bot`
3. Перейди во вкладку **Variables** и добавь:
   ```
   DISCORD_TOKEN = {токен бота, скопированный из Developer Portal}
   DUELS_CHANNEL_ID = {ID канала, где будут объявляться дуэли}
   LEADERBOARD_MESSAGE_ID = {оставь пусто, заполнится автоматически}
   LEADERBOARD_CHANNEL_ID = {оставь пусто, заполнится автоматически}
   ```
4. Railway автоматически передеплоит бота

### Шаг 4: Инициализация лидерборда

1. На сервере напиши команду `!leaderboard` в нужном канале
2. Бот создаст основное сообщение с кнопкой
3. **В консоли Railway** появятся строки типа:
   ```
   Сохрани в Railway переменные:
   LEADERBOARD_MESSAGE_ID=123456789...
   LEADERBOARD_CHANNEL_ID=987654321...
   ```
4. Скопируй эти значения в Railway → **Variables** и сохрани
5. Бот автоматически обновится

## 📊 Переменные окружения (Railway)

| Переменная | Описание | Пример |
|---|---|---|
| `DISCORD_TOKEN` | Токен бота | `MTA4MzMyODI0OTcxOTExNzM2...` |
| `DUELS_CHANNEL_ID` | ID канала для объявления дуэлей | `1234567890123456789` |
| `LEADERBOARD_MESSAGE_ID` | ID сообщения лидерборда (заполняется автоматически после `!leaderboard`) | `1234567890123456789` |
| `LEADERBOARD_CHANNEL_ID` | ID канала лидерборда (заполняется автоматически после `!leaderboard`) | `1234567890123456789` |

## 📁 Хранение данных

Бот автоматически создаёт на сервере Railway два JSON-файла:
- `leaderboard.json` — текущие позиции в лидерборде
- `duels.json` — активные дуэли с таймерами

Эти файлы автоматически обновляются при каждом изменении.

## 🎮 Примеры использования

### Команда !top-10
```
!top-10

TOP 1-10

1. Player1 | Ник_Роблокса | https://www.roblox.com/users/123/profile
2. Player2 | Другой_Ник | https://www.roblox.com/users/456/profile
3. [VACANT] | [VACANT] | [VACANT]
...
```

### Претензия на место
1. Нажимаем кнопку **"Атаковать место"**
2. Заполняем форму:
   - Место: `5`
   - Discord: `MyName#1234`
   - Roblox: `MyRobloxNick`
   - Ссылка: `https://www.roblox.com/users/789/profile`
3. Если место 5 свободно → встаём туда
4. Если занято → объявляется дуэль в канале дуэлей

### Дуэль
```
⚔️ ДУЭЛЬ ⚔️

@Attacker атакует место 5!

@Defender защищается.

Таймер: 3 дня. После времени место не изменится, если защитник не проиграет.

[Кнопка: Атакующий выиграл]
```

## ⚠️ Важные моменты

1. **Уникальность мест:** Один игрок не может занимать два места одновременно
2. **Заполнение мест:** Все пустые места отмечены как `[VACANT]`
3. **Таймеры:** Таймеры дуэлей **сохраняются в памяти бота**. Если бот перезагрузится, оставшееся время дуэли может сброситься (можно добавить сохранение в JSON)
4. **Свайп мест:** Места всегда свапаются — атакующий идёт на место защитника, защитник идёт на старое место атакующего

## 🔧 Решение проблем

### Бот не отвечает на команды
- Проверь, что **Message Content Intent** включён в Developer Portal
- Проверь, что бот приглашён на сервер с правильными permissions

### Форма не открывается при клике кнопки
- Проверь Railway Logs на ошибки
- Убедись, что бот запущен (статус "online")

### Лидерборд не обновляется
- Перезагрузи сообщение (`!leaderboard` заново) или проверь консоль Railway на ошибки
